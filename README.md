# TecnoMovilData

# Descripción del proyecto

TecnoMovilData es un proyecto académico desarrollado en Java que simula el procesamiento funcional de datos para un sistema de gestión de transporte urbano.

El programa analiza registros de pasajeros para obtener información sobre la afluencia en estaciones, las horas de mayor movimiento, las rutas más utilizadas, los patrones de viaje y la detección de rutas con alta demanda.

# Objetivo

Aplicar conceptos del paradigma de programación funcional en Java mediante el uso de Streams, expresiones lambda y funciones de procesamiento de datos.

# Funcionalidades

El programa implementa los siguientes requerimientos:

1. **Afluencia por estación:** cuenta las entradas registradas en cada estación.
2. **Horas pico:** agrupa las entradas por hora.
3. **Rutas más utilizadas:** cuenta las entradas por ruta.
4. **Patrones de viaje:** organiza las estaciones visitadas por cada usuario según la fecha y hora.
5. **Tiempo promedio:** calcula el intervalo promedio, en minutos, entre registros consecutivos del mismo usuario.
6. **Rutas sobrecargadas:** identifica las rutas que superan un umbral de entradas establecido.
